Minecraft **1.21.1**, NeoForge **21.1.249**. Client pack **1.7.1** for `play.create.anechoicaxolotl.com`.

- **Prism.zip:** Import with Prism Launcher using Add Instance → Import.
- **.mrpack:** Import with Prism or another launcher that supports Modrinth packs.
- **Configs.zip:** Settings, controls, and the resource pack for an existing installation of this version.
- **SHA256SUMS.txt:** Checksums for the downloads.

Both import formats fetch the exact mod and shader files from Modrinth. They include the same 132 mods and client configs. Use Java 21 and allow up to 8 GiB of memory. These are online imports, not offline bundles.
